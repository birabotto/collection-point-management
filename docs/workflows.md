# Example Workflows

## Order receiving

1. Create or import a fictional order.
2. Validate the order number.
3. Assign a status and scheduled date.
4. Display the order in search and daily views.

## Customer pickup

1. Find a fictional order.
2. Check whether it has already been picked up.
3. Prefill the receiver name from the customer name, allowing editing.
4. Validate receiver details and signature.
5. Record a pickup event and update the status.
6. Show the confirmation view.

These are demonstration requirements, not claims of production deployment. Use a transactional or appropriately recoverable server-side process for real writes.
