# Public Portfolio Safety

This repository contains independently authored demonstration material only.

- Never commit an employer's Power Apps exports, original YAML, solution packages or proprietary assets without permission.
- Never commit real order records, names, signatures, internal endpoints, credentials, tenant IDs or connection references.
- Use newly created screenshots with fictional information and original branding.
- Do not assume removing sensitive content from the latest commit removes it from Git history.
- Keep actual app exports and environment-specific configuration private.

The project is not affiliated with any employer.
