# Collection Point Management — Portfolio Demo

Independent demonstration of a customer order collection workflow using **Microsoft Power Apps**, **Power Fx**, **Dataverse**, and **Power Automate**.

> **Portfolio concept only.** This repository does not contain employer-owned source code, production connections, customer records, original corporate screenshots, or proprietary branding. It is not a deployable export of an existing company application.

## Features illustrated

- Order receiving and today's orders
- Search by order number, customer name, or barcode
- Order status tracking and completed-order filtering
- Customer pickup confirmation with receiver details
- Signature capture workflow concept
- Operational dashboard and reporting
- Responsive Canvas App design

## Technologies

Microsoft Power Apps (Canvas Apps), Power Fx, Microsoft Dataverse, Power Automate.

## Repository structure

- `docs/` — architecture, fictional data model, workflows and publication safety
- `src/powerfx/` — independently written Power Fx examples
- `screenshots/` — placeholders for newly created fictional demo screens

## Demo process

1. Create a fictional order.
2. Find the order using the search screen.
3. Confirm the receiver name and capture a signature in a personal demo environment.
4. Update the order to **Picked Up**.
5. Review the confirmation and operational metrics.

These are illustrative examples. Rebuild controls, Dataverse tables, connections, permissions, and flows in your own Microsoft environment before testing.
